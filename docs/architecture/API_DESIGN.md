# API Design

> Status: SKELETON. Detailed contracts are Stage 2 work. Source: plan §10.

## Conventions (decided)
- Versioned REST under `/api/v1`; OpenAPI generated by FastAPI.
- Validate all input; authorize every protected operation server-side; consistent error envelope (format TBD in Stage 2).
- Polling for job progress initially; SSE/WebSockets only if UX needs it.
- No endpoint executes arbitrary commands. A run/project ID alone is never proof of access.

## Endpoint groups (planned, not implemented)
`/auth`, `/users` + `/admin`, `/projects`, `/test-plans`, `/test-runs` (+ `/{id}/batches`), `/findings`, `/alerts`, `/artifacts`, `/reports`, `/chat`, `/health`.
